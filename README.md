# El Estuche ✏️

Aplicación web para organizar el trabajo de un grupo de estudio: asignaturas, trabajos, tareas y fechas importantes en un mismo lugar, sincronizados en tiempo real.

## Funcionalidades

- Gestión de asignaturas y trabajos
- Tareas asignadas por persona, con seguimiento del progreso
- Registro de avances con imágenes, archivos y enlaces
- Calendario de entregas y exámenes
- Integración con Google Calendar
- Sincronización en tiempo real entre usuarias
- Asistente de IA que ayuda a organizar y planificar el trabajo
- Diseño responsive, adaptado a móvil y escritorio

## Tecnologías

- **Frontend:** React y esbuild
- **Backend:** Supabase (PostgreSQL, Realtime, Storage y Auth)
- **IA:** Google Gemini
- **Despliegue:** GitHub Pages y GitHub Actions
